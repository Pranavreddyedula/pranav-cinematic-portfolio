# Pranav — Cinematic Portfolio

A personalized cinematic portfolio inspired by the structure and visual language of the reference portfolio, with original copy and Pranav's projects/links.

## Run locally
1. Extract the ZIP.
2. Keep `assets/walking-hero.mp4` in the `assets` folder beside `index.html`.
3. Open `index.html` in Chrome. If autoplay is blocked, click the page once.

## Publish
Upload `index.html` and the `assets` folder together to your static hosting or GitHub repository. The video path is relative (`assets/walking-hero.mp4`).

## Personal details to verify
Update project links, email, and social URLs in `index.html` if any details change.
